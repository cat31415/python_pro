Часть 2. Практика
Проект: Мини интернет-магазин

Необходимо реализовать небольшой интернет-магазин без базы данных.

Все данные хранятся в обычных списках Python.

Структура проекта

Проект должен содержать следующие папки:

project/

├── main.py

├── models/
│   └── product.py

├── storage/
│   └── data.py

├── services/
│   └── product_service.py

└── routers/
    └── product_router.py
Модель товара

Создайте модель товара.

Product

Поля:

id: int
name: str
price: float

Пример:

{
    "id": 1,
    "name": "iPhone 17",
    "price": 1200
}
Хранилище

Создайте список товаров.

Например:

products = []
Реализовать эндпоинты
1. Получение списка товаров
GET /products

Ответ:

[
    {
        "id": 1,
        "name": "Keyboard",
        "price": 100
    }
]
2. Создание товара
POST /products

Запрос:

{
    "name": "Keyboard",
    "price": 100
}

Ответ:

{
    "id": 1,
    "name": "Keyboard",
    "price": 100
}
3. Получение товара по id
GET /products/{id}

Пример:

GET /products/1
4. Удаление товара
DELETE /products/{id}

Если товара нет — вернуть ошибку.

Бизнес-логика

Реализовать в слое Service.

Правило 1

Название товара не может быть пустым.

Нельзя:

{
    "name": "",
    "price": 100
}
Правило 2

Цена должна быть больше нуля.

Нельзя:

{
    "name": "Keyboard",
    "price": -10
}
Правило 3

Цена не может превышать 100000.

Правило 4

Названия товаров должны быть уникальными.

Если товар с таким названием уже существует:

{
    "detail": "Product already exists"
}
Дополнительное задание (по желанию)

Добавить эндпоинт:

GET /products/premium

Он должен возвращать только товары стоимостью более 1000.

Пример ответа:

[
    {
        "id": 3,
        "name": "MacBook",
        "price": 2500
    }
]
