# Легенда

Представьте, что вы работаете программистом на космической станции на Марсе.

На станции есть роботы, которые выполняют различные миссии:

* исследуют поверхность планеты;
* добывают полезные ископаемые;
* строят новые модули станции.

Ваша задача — создать API для управления роботами.

---

# Исходные данные

Создайте список роботов:

```python
robots = [
    "Explorer-1",
    "Builder-2",
    "Miner-3"
]
```

---

# Задание 1. Получить список роботов

Создайте маршрут:

```python
GET /robots
```

Он должен возвращать список всех роботов станции.

Пример ответа:

```json
[
    "Explorer-1",
    "Builder-2",
    "Miner-3"
]
```

---

# Задание 2. Получить робота по номеру

Создайте маршрут:

```python
GET /robots/{robot_id}
```

Используйте Path Parameter.

Пример запроса:

```text
/robots/0
```

Ответ:

```json
{
    "robot": "Explorer-1"
}
```

---

# Задание 3. Добавить нового робота

Создайте маршрут:

```python
POST /robots
```

Используйте Query Parameter:

```python
name: str
```

Пример запроса:

```text
/robots?name=Scout-7
```

После выполнения робот должен добавляться в список.

Ответ:

```json
{
    "message": "Робот успешно добавлен"
}
```

---

# Задание 4. Назначить миссию

Добавить роботам миссии:

```python
robots = [
    {"name": "Explorer-1", "mission": "Исследование поверхности Марса"},
    ...
]
```

Создайте маршрут:

```python
GET /mission
```

Используйте Query Parameter:

```python
robot: str
```

Пример:

```text
/mission?robot=Explorer-1
```

Ответ:

```json
{
    "robot": "Explorer-1",
    "mission": "Исследование поверхности Марса"
}
```
Создайте маршрут:

POST ```/mission```
Используйте Query Parameter:

robot: str
mission: str


Для разных роботов можно возвращать разные миссии.

Например:

```text
Explorer-1 → Исследование поверхности
Builder-2 → Строительство базы
Miner-3 → Добыча ресурсов
```

# Задание 5. Информация о станции

Создайте маршрут:

```python
GET /station
```

Ответ должен содержать информацию о станции.

Пример:

```json
{
    "name": "Mars Alpha",
    "planet": "Mars",
    "robots_count": 3
}
```

Количество роботов должно вычисляться через:

```python
len(robots)
```

# Задание 6. Оформление Swagger

Добавьте описание приложения:

```python
app = FastAPI(
    title="Mars Station API",
    description="Система управления роботами на Марсе",
    version="1.0"
)
```

---

Добавьте `summary` и `description` минимум для двух маршрутов.

Пример:

```python
@app.get(
    "/robots",
    summary="Получить список роботов",
    description="Возвращает всех роботов космической станции"
)
```
