# Задание 1. Task Board

Фронтенд одностраничной доски задач готов. Напишите API в `main.py`, чтобы можно
было добавлять, завершать и удалять задачи.

## Запуск

```bash
uvicorn main:app --reload
```

Откройте <http://127.0.0.1:8000>. Пока API не написан, страница честно покажет
ошибку подключения. Swagger доступен на <http://127.0.0.1:8000/docs>.

## Формат задачи

```json
{
  "id": 1,
  "title": "Повторить модели Pydantic",
  "priority": "high",
  "done": false
}
```

`priority` принимает только `low`, `medium` или `high`.

## Контракт API

| Метод и URL | Тело запроса | Ответ | Статус |
|---|---|---|---:|
| `GET /api/tasks` | нет | `{"items": [...]}` | 200 |
| `POST /api/tasks` | `{"title": "...", "priority": "high"}` | созданная задача | 201 |
| `PATCH /api/tasks/{task_id}` | `{"done": true}` | изменённая задача | 200 |
| `DELETE /api/tasks/{task_id}` | нет | пустой ответ | 204 |

Неизвестный `task_id` должен возвращать `404` и понятный `detail`.

## Обязательные требования

1. Храните задачи в списке словарей.
2. Создайте модели `TaskCreate` и `TaskUpdate`.
3. Ограничьте длину заголовка: от 2 до 80 символов.
4. Новый `id` не должен повторяться после удаления задачи.
5. Для ошибки используйте `HTTPException`, не возвращайте словарь с ключом
   `error` и статусом 200.
6. При удалении верните `Response(status_code=204)` или настройте такой статус в
   декораторе без JSON-тела.

## Подсказки

Разрешённые значения удобно описать так:

```python
from typing import Literal

priority: Literal["low", "medium", "high"]
```

Поиск по id:

```python
task = next((item for item in tasks if item["id"] == task_id), None)
```


браузера (до перезапуска Uvicorn).
