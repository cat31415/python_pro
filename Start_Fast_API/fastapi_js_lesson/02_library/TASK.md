# Задание 2. Shelf — каталог книг

У приложения две страницы:

- `/` — каталог с поиском и фильтром;
- `/favorites` — сохранённые книги.

Напишите серверную часть в `main.py`. Фронтенд менять не требуется.

## Запуск

```bash
uvicorn main:app --reload
```

## Контракт API

| Метод и URL | Что возвращает | Статус |
|---|---|---:|
| `GET /api/genres` | `{"items": ["Python", "Web", ...]}` | 200 |
| `GET /api/books` | `{"items": [...], "total": 4}` | 200 |
| `GET /api/books?query=python` | книги, где строка есть в названии или авторе | 200 |
| `GET /api/books?genre=Python` | книги выбранного жанра | 200 |
| `GET /api/favorites` | `{"items": [...]}` с полными объектами книг | 200 |
| `POST /api/favorites` | тело `{"book_id": 1}`, ответ — объект книги | 201 |
| `DELETE /api/favorites/{book_id}` | пустой ответ | 204 |

Фильтры `query` и `genre` должны работать одновременно и без учёта регистра.

## Ошибки

- неизвестная книга при добавлении: `404`;
- книга уже в избранном: `409`;
- удаление книги, которой нет в избранном: `404`.

Для тела POST создайте модель:

```python
class FavoriteCreate(BaseModel):
    book_id: int
```

## Алгоритм поиска

1. Начните со всех книг.
2. Если передан `query`, оставьте совпадения по `title` или `author`.
3. Если передан `genre`, примените второй фильтр к уже полученному списку.
4. Верните список и его длину в `total`.
