**1. Пользователи с цифрой 7 в почтовом индексе**

Ручка: `/users`.

Найди пользователей, у которых в почтовом индексе встречается цифра `7`.

Сформируй **список словарей**, содержащих имя пользователя, город и почтовый индекс. Выведи список и количество найденных пользователей.

Подсказка: индекс находится в `address → zipcode`. Обрабатывай его как строку.

**2. Фильтр по имени и электронной почте**

Ручка: `/users`.

Найди пользователей, у которых одновременно:

- поле `name` начинается с латинской буквы `C`;
- email заканчивается на `.biz`.

Проверки должны работать без учёта регистра.

Сформируй **словарь**, где ключ — ID пользователя, а значение — словарь с его именем и email.


**3. Пользователи, выполнившие больше половины задач**

Ручки: `/users` и `/todos`.

Для каждого пользователя посчитай общее количество задач и количество выполненных. Найди пользователей, выполнивших **строго больше 50%** своих задач.

Сформируй **список словарей** с полями:

- `name` — имя;
- `total` — всего задач;
- `completed` — выполнено;
- `percent` — процент выполнения.

Если у пользователя нет задач, не включай его в результат.

Подсказка: `userId` задачи соответствует `id` пользователя. Выполнение определяется полем `completed`.

**4. Авторы публикаций с определённым текстом**

Ручки: `/users` и `/posts`.

Найди публикации, в заголовках которых встречается **подстрока `qui`**, без учёта регистра. Сгруппируй найденные публикации по пользователям.

Сформируй **словарь**, где:

- ключ — ID пользователя;
- значение — словарь с именем пользователя и списком подходящих публикаций;
- каждая публикация представлена словарём с полями `id` и `title`.

Оставь в результате только пользователей, у которых найдено **не меньше трёх** подходящих публикаций.

**5. Публикации с комментариями из доменов `.com`**

Ручки: `/users`, `/posts` и `/comments`.

Найди публикации, удовлетворяющие двум условиям:

- заголовок содержит **меньше 60 символов**, включая пробелы;
- у публикации есть **минимум два комментария**, авторы которых указали email, заканчивающийся на `.com`.

Сформируй **список словарей** с ID публикации, заголовком, именем автора публикации, количеством подходящих комментариев и списком email из этих комментариев.

Подсказка: комментарий связан с публикацией через `postId`, а публикация с пользователем — через `userId`. Считать нужно именно комментарии, прошедшие проверку email.

Для всех пяти задач: результаты вычисляй из ответа API; если ничего не найдено, выводи сообщение `Ничего не найдено`.
