# Демонстрация «Кофейная очередь»

Это готовое приложение, которое преподаватель разбирает от действия пользователя
к серверному маршруту. На объяснение достаточно 20–25 минут.

## Запуск

```bash
uvicorn main:app --reload
```

Интерфейс: <http://127.0.0.1:8000>, Swagger: <http://127.0.0.1:8000/docs>.

## Контракт

| Метод и URL | Что делает | Успешный статус |
|---|---|---:|
| `GET /api/drinks` | возвращает меню | 200 |
| `GET /api/orders` | возвращает очередь | 200 |
| `POST /api/orders` | создаёт заказ | 201 |
| `PATCH /api/orders/{order_id}/ready` | помечает заказ готовым | 200 |

## Сценарий объяснения

### 1. Первый GET

Откройте Network в инструментах разработчика и обновите страницу. Найдите
`GET /api/drinks`.

Фраза для объяснения:

> Браузер не импортирует Python-функцию. Он знает только адрес `/api/drinks`.
> FastAPI связывает этот адрес с функцией и превращает Python-словарь в JSON.

Сопоставьте `loadDrinks()` в `frontend/app.js` и `get_drinks()` в `main.py`.

### 2. Первый POST

Введите имя, выберите напиток и нажмите «Добавить в очередь». До нажатия попросите
учеников предсказать JSON. Затем покажите Payload во вкладке Network.

Сопоставьте поля с `OrderCreate`. Временно добавьте `print(payload)` в маршрут.

### 3. Три уровня проверки

1. JS не отправляет пустую строку, чтобы быстро помочь пользователю.
2. Pydantic проверяет типы и длину имени, даже если запрос отправлен не из нашего UI.
3. Маршрут проверяет, существует ли `drink_id`, потому что одной проверки типов мало.

### 4. Статусы

- `201`: создан новый объект;
- `404`: напиток или заказ не найден;
- `422`: JSON не прошёл проверку модели;
- `200`: объект прочитан или успешно изменён.

### 5. Path-параметр и PATCH

Нажмите «Заказ готов». В адресе появится id конкретного заказа. `PATCH` означает,
что меняется только часть объекта, здесь поле `status`.

## Вопросы классу

- Что сломается, если JS отправит `drinkId`, а модель ждёт `drink_id`?
- Почему проверка пустого имени только в JavaScript недостаточна?
- Почему сервер возвращает весь созданный заказ, а не только `{"ok": true}`?
- Где пропадёт очередь после перезапуска и что понадобится для постоянного хранения?

Последний вопрос оставляет мост к следующему занятию про базу данных.
